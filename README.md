# TyperReflex

Aplicación de test de mecanografía (typing test) con React, TypeScript y Vite.

## Requisitos

- Node.js 20+
- npm

## Instalación

```bash
npm install
```

## Scripts

```bash
npm run dev        # servidor de desarrollo
npm run build      # build de producción
npm run typecheck  # chequeo de tipos
npm run preview    # preview del build
```
